## Was ist Kubernetes?

[Kubernetes][kubernetes], auch als K8s bekannt, ist eine Open-Source-Plattform zur
Container-Orchestrierung. Mithilfe von Kubernetes können Container-Anwendungen in
einem grossen Massstab bereitgestellt, verwaltet und skaliert werden.  
Zentral besteht Kubernetes aus einem Cluster von Rechnern, welche die unterschiedlichen
Container ausführen.

[kubernetes]: https://kubernetes.io/
